## Scope and mode

`portal/index.html` is the public product portal. Visitor mode: Persuade.

## Audience, job, and action

The visitor is a Windows Destiny 2 player evaluating a small open-source calibration tool. They need to understand what the program controls, what it does not automate, and whether they can stop it safely. The primary action is downloading the latest Windows installer. Opening the GitHub repository is the secondary action.

## Proof and constraints

The page demonstrates the actual calibration model: resolution, sensitivity, aiming offsets, timing, seven visible phases, the read-only overlay, and F10 cancellation. It must not claim in-game success, state recognition, automatic loops, or loot collection. It uses the existing D2 monogram and calibrated Windows utility language in light and dark modes.

## Direction and memorable moment

The direction is a dual-mode calibration stage. The first viewport pairs short product copy and download controls with a detailed console preview whose light and dark states can be switched in place. This makes theme support and the inspectable control model visible without relying on game artwork.
