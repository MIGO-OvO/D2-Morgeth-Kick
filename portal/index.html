02 / Reconstruction Explanation

重构说明

在原作者的程序基础上实现了以下改动与重构

01

底层重构

在他人项目基础上重新整理架构，让执行、配置和界面各自负责明确的部分。

02

体积更小

使用 Tauri 与 Rust 承载桌面端和动作执行，保留必要能力，减少程序负担。

03

GUI 更顺手

设置、运行状态、快捷键和停止入口集中在一个窗口，改值不必来回找配置。

04

参数更多

分辨率、灵敏度、三组瞄准偏移、六项等待时间和按键映射都可以在界面中调整。
